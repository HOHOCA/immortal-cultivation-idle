## 🎮 快速开始

### 第一次游戏

**初始操作流程：**
1. 打开`index.html`
2. 按`?`键查看快捷键帮助
3. 按`Space`开始修炼
4. 点击"存档管理"标签（或按`9`），导出一次存档（重要！）

**前5分钟要做的事：**
- 多次按`Space`修炼积累灵力
- 突破进度到100%后按`B`突破
- 用灵石升级"灵脉"设施
- 开始自动获取灵力

**核心资源：**
- **灵力**：用于突破境界，自动产出（每秒）
- **灵石**：用于升级设施和功法
- **丹药**：快速增加灵力和突破进度

## 🏆 核心系统

### 1. 境界系统

**凡界九大境界：**
```
炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 
   → 炼虚期 → 合体期 → 大乘期 → 渡劫期
```

每个境界有9层，从第1层修炼到第9层，然后突破进入下一境界。

**突破机制：**
- 灵力达到要求值
- 突破进度100%时可以突破
- 基础成功率70%
- 失败会损失50%灵力
- 成功后进入下一层/境界

**快速突破技巧：**
1. 升级"藏经阁"提高成功率
2. 修炼功法增加成功率
3. 使用丹药提升突破进度
4. 加入门派获得加成

### 2. 资源系统

**基础资源：**

| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 灵力 | 自动产出、修炼、丹药 | 突破境界 |
| 灵石 | 修炼获得、灵田产出 | 升级设施和功法 |
| 丹药 | 丹房自动产出、任务奖励 | 增加灵力（100/个） |

**高级资源（后期解锁）：**

| 资源 | 解锁条件 | 获取方式 | 用途 |
|------|---------|---------|------|
| 仙石 | 筑基期 | Boss、副本、NPC交易 | 购买珍贵物品、提升五行 |
| 道果 | 金丹期 | Boss、副本、随机事件 | 激活天赋 |
| 天道精华 | 炼虚期 | Boss奖励 | 炼器材料（未来） |

**资源管理建议：**
- 前期：灵石优先升级灵脉
- 中期：灵石用于丹房和藏经阁
- 后期：积累仙石和道果

### 3. 设施系统

**7大设施详解：**

**灵脉（Lv.1起始）**
- 效果：提升灵力产出速度
- 优先级：⭐⭐⭐⭐⭐（最高）
- 建议：前期优先升级，是灵力的主要来源

**丹房（需建造）**
- 效果：每30秒自动产出1丹药
- 优先级：⭐⭐⭐⭐
- 建议：越早建造越好，丹药很重要

**藏经阁（需建造）**
- 效果：提升灵力获取5%/级，提升突破成功率5%/级
- 优先级：⭐⭐⭐⭐⭐
- 建议：突破困难时优先升级

**炼器房（需建造）**
- 效果：整体效率+3%/级
- 优先级：⭐⭐⭐
- 建议：有余力时升级，全面提升

**灵田（需建造）**
- 效果：每分钟产出灵石
- 优先级：⭐⭐⭐
- 建议：中期建造，被动收入

**仙池（飞升1次解锁）**
- 效果：灵力产出+50%/级
- 优先级：⭐⭐⭐⭐⭐
- 建议：飞升后立即建造

**仙树（飞升2次解锁）**
- 效果：每小时产出灵石和丹药
- 优先级：⭐⭐⭐⭐
- 建议：飞升2次后建造

**升级策略：**
```
初期：灵脉 → 丹房 → 藏经阁
中期：灵脉 → 藏经阁 → 炼器房 → 灵田
后期：全面升级，飞升设施优先
```

### 4. 功法系统

**功法分类：**

**师传功法（v3.0新增）：**
- 通过拜师学习获得，在修炼界面"师传功法"分类中显示
- 每个功法都有详细的加成效果说明
- 例如：御剑飞行（灵力 +500、移动速度 +20%、战斗伤害 +10%）
- 学会后永久生效，无需升级

**基础功法（炼气期可学）：**
- 基础心法：基础加成15%/级
- 火焰之道：高攻击，18%加成/级
- 水之心法：均衡，17%加成/级
- 炼体诀：12%加成/级，额外+2%突破率/级

**进阶功法（筑基期解锁）：**
- 高级心法：25%加成/级
- 剑意心经：高攻击，28%加成/级
- 法术精通：法术强化，27%加成/级

**顶级功法（金丹期解锁）：**
- 至尊功法：40%加成/级（金丹期）
- 天道玄功：超强45%加成/级（元婴期）
- 虚空秘典：最强50%加成/级（化神期）

**飞升功法（飞升后解锁）：**
- 仙基心法：60%加成/级（飞升1次，最高15级）
- 仙元功：80%加成/级（飞升3次，最高15级）
- 永恒大道：100%加成/级+1%突破率/级（飞升5次，最高20级）

**修炼建议：**
1. 初期专精一个功法（建议火焰之道或水之心法）
2. 到筑基期学习进阶功法
3. 同时保留炼体诀（提升突破率）
4. **优先学习师传功法**：通过拜师获得，效果显著且永久生效
5. 后期尽量学习所有功法（成就需要）
6. 飞升功法可以无限升级，是后期主要提升来源

## 🏛️ 门派系统

### 门派选择

**达到筑基期后可以选择门派：**

#### 正派门派（4个）
- **剑宗** ⚔️：灵力获取+30%，突破成功率+5%
- **丹宗** 🧪：丹房产出+2，灵石获取+50%
- **阵宗** 🔮：灵力获取+20%，设施效果+20%
- **佛宗** 🙏：灵力获取+25%，突破成功率+8%，丹房产出+1

#### 中立门派（3个）
- **道宗** ☯️：全属性+15%，灵力获取+15%，设施效果+15%
- **商会** 💰：灵石获取+100%，丹房产出+3，设施效果+30%
- **散修** 🗡️：全属性+10%，无门派任务（适合不想做任务的玩家）

#### 反派门派（3个）
- **魔宗** 😈：灵力获取+50%，突破成功率+10%，全属性+20%
- **邪教** 👿：灵力获取+40%，灵石获取+60%，设施效果+25%
- **血煞门** 🩸：灵力获取+60%，突破成功率+15%，全属性+25%

### 🏔️ 堂口系统（v3.0新增）

**每个门派有3个堂口/峰头/洞府（共27个）**

在门派界面点击"拜师入堂口"按钮后选择师傅 = 选择堂口，每个堂口有独特的修炼方向和属性加成。

#### 堂口示例

**剑宗：**
- **剑心峰**（张剑心）：基础修炼，突破率+8%
- **剑意峰**（李如雪）：攻击修炼，灵力+35%
- **剑魂峰**（王小虎）：感悟修炼，全属性+15%

**丹宗：**
- **炼丹堂**（陈药王）：炼丹技艺，丹药产出+3
- **药园**（赵清雅）：药材收集，灵石+60%
- **丹方阁**（孙小药）：配方研究，全属性+12%

**商会：**
- **商道总会**（钱多多）：商道经营，灵石+120%，设施+35%
- **珍宝阁**（金玲珑）：鉴宝寻宝，灵石+100%，丹药+4
- **交易所**（小富贵）：物资交易，全属性+20%

其他门派（阵宗、佛宗、道宗、魔宗、邪教、血煞门）同样各有3个堂口，进入游戏后可查看详情。

#### 堂口功能

**堂口任务：**
- 每个堂口有3-5个专属任务
- 完成任务获得堂口贡献度
- 同时增加门派贡献度（一半）
- 在门派界面点击"堂口任务"按钮

**堂口商店：**
- 使用堂口贡献度兑换物品
- 通用商品：丹药、灵石、秘传心法、师傅指点
- 堂口专属：特殊功法、宝物等
- 在门派界面点击"堂口商店"按钮

#### 堂口选择建议

**新手推荐：**
- 剑心峰、禅修院：突破率高，快速升级
- 清虚殿：全属性加成，均衡发展

**资源型：**
- 药园、商道总会、珍宝阁：灵石获取高

**战力型：**
- 剑意峰、魔神殿、血神殿：灵力获取高（注意反派会被追杀）

### 门派特色

**正派特点：**
- 修炼相对安全稳定
- 帮助魔修会降低正派NPC好感
- 适合新手玩家

**中立特点：**
- 不受阵营冲突影响
- 平衡发展，无特殊限制
- 适合稳健型玩家

**反派特点：**
- 修炼速度最快，加成最高
- 会被正派NPC敌视
- 适合追求高收益的玩家

### 门派与堂口贡献

**门派贡献度：**
- 完成门派任务
- 完成堂口任务（获得一半）
- 参与门派活动

**堂口贡献度（新增）：**
- 完成堂口专属任务
- 用于兑换堂口商店物品

**消耗贡献度：**
- 购买门派商店物品
- 购买堂口商店物品
- 拜客座师傅（50门派贡献）

## 👥 人际关系系统

本版本重构了人际系统，采用"认识后可见"的渐进式解锁：

- 使用 `gameData.knownNPCs` 记录已认识的NPC，仅显示这些NPC；NPC数据按需初始化，性能更好。
- 解锁路径：
  - **加入门派**：加入门派后自动认识同门师兄姐，可在门派界面选择拜师入堂口（非必须）。
  - 门派贡献：贡献度达到阈值会逐步解锁更多同门（50解锁师弟妹，100+解锁更多成员）。
  - 随机事件：新增"偶遇修士、遇到同门、门派聚会、修士求助、门派交流"等事件，可快速结交新朋友。
  - 互动"请求介绍"：关系等级≥3时可用，可由熟人介绍新NPC，消耗少量灵石，1天冷却；被介绍NPC初始好感+5。

交互刷新：关系面板支持分门派展示，新增内联SVG图标，整体观感更统一。

### 🎓 拜师系统（v3.0新增）

#### 快速入门

**第一步：加入门派**
1. 修炼到**筑基期**
2. 自动弹出门派选择界面
3. 选择一个门派（9选1）
4. 完成加入，结识同门师兄姐

**第二步：拜师入堂口（可选）**
1. 在"门派"标签页点击"拜师入堂口"按钮
2. 选择一位师傅（3选1）= 同时选择了堂口
3. 观看拜师仪式
4. 完成！获得初始好感度20

**第三步：提升师傅好感度**
- 与师傅互动（问候、闲聊、赠礼等）
- 完成堂口任务
- 帮助师傅修炼
- 触发师傅专属事件

**第四步：学习功法**
- 好感度达到20/50/80解锁不同功法
- 点击"请教功法"按钮（24小时CD，消耗200灵石）
- 选择想学的功法
- 学会后永久掌握，在修炼界面的"师传功法"分类中查看
- **新功能**：师传功法会显示详细的加成效果，如"灵力 +500、移动速度 +20%、战斗伤害 +10%"

#### 师傅类型

| 类型 | 数量限制 | 获取条件 | 加成 | 学习功法 |
|------|---------|---------|------|---------|
| **正式师傅** | 1位 | 拜师时选择 | 灵力+10% | ✅ 全部 |
| **客座师傅** | 无限制 | 好感60+，500灵石+50贡献 | 每位+3% | ✅ 全部 |

**如何拜客座师傅：**
1. 提升NPC好感度至60+
2. 在人际关系中找到该NPC
3. 点击"拜为客座师傅"按钮
4. 完成拜师仪式

#### 功法解锁进度表

| 好感度 | 解锁内容 |
|--------|---------|
| 20 | 第1个功法（基础） |
| 30 | 触发"师傅指点"事件 |
| 40 | 触发"师门考核"事件 |
| 50 | 第2个功法（进阶）；触发"师傅遇险" |
| 60 | 触发"师傅突破"事件；可拜客座师傅 |
| 70 | 触发"师傅馈赠"事件 |
| 80 | 第3个功法（秘传） |
| 90 | 可触发"共同飞升"（需忠诚80+） |

#### 师傅专属事件

1. **师傅指点**（好感30+）：获得大量灵力和修炼心得
2. **师门考核**（好感40+）：通过考核获得奖励
3. **师傅遇险**（好感50+）：救援可能获得绝学！
4. **师傅突破**（好感60+）：护法帮助师傅提升境界
5. **师傅馈赠**（好感70+）：获得修炼资源
6. **共同飞升**（好感90+忠诚80+）：终极奖励！

#### 🌟 师徒共同飞升（终极目标）

**触发条件：**
- 师傅达到渡劫期8层+
- 师傅好感度≥90
- 师傅忠诚度≥80
- 玩家达到渡劫期9层

**特殊奖励：**
- 保留**70%**灵石和丹药（比普通飞升多20%）
- 获得**200仙石**（多100）
- 获得**3道果**（多2）
- 解锁永久**"师徒同心"**加成（全属性+5%）
- 师傅一起进入仙界，继续陪伴

#### 师傅成长机制

- ✨ 师傅境界会随时间自动成长
- ✨ 玩家境界越高，师傅成长越快
- ✨ 玩家突破大境界时，师傅好感度自动提升
- ✨ 好感度越高，师傅成长速度越快
- ✨ 最终可培养师傅至渡劫期并共同飞升

### NPC互动

**每个门派都有3个独特的NPC：**
- **掌门/师尊**：传授功法，给予指导
- **师兄/师姐**：切磋交流，共同修炼
- **师弟/师妹**：互相帮助，建立友谊

### 关系属性

**三种关系数值：**
- **好感度**：基础友好程度
- **忠诚度**：对玩家的信任程度
- **信任度**：深层次的信任关系

### 关系等级

**5个关系等级及解锁功能：**

| 等级 | 名称 | 好感度范围 | 解锁功能 |
|------|------|-----------|---------|
| 1 | 陌生 | 0-20 | 只是刚刚认识 |
| 2 | 认识 | 21-40 | 可进行基本交流、接取简单任务 |
| 3 | 友好 | 41-60 | 可赠送礼物、获得建议、共享资源 |
| 4 | 亲密 | 61-80 | 可学习技能、获得战斗支援、接取特殊任务 |
| 5 | 挚友 | 81-100 | 获得全面支持、秘传功法、可以一起飞升 |

### 互动方式详解

**4种基础互动：**

**1. 闲聊**
- 好感度：+2
- 消耗：无
- 冷却：1小时
- 最低等级：认识（好感21+）
- 说明：与NPC聊天增进感情

**2. 赠送礼物**
- 好感度：+10
- 消耗：100灵石
- 冷却：1天（24小时）
- 最低等级：认识（好感21+）
- 说明：赠送灵石表达心意

**3. 切磋武艺**
- 好感度：+5
- 消耗：50灵力
- 冷却：6小时
- 最低等级：友好（好感41+）
- 说明：与对方切磋，增进了解

**4. 帮助修炼**
- 好感度：+8
- 消耗：100灵力
- 冷却：12小时
- 最低等级：友好（好感41+）
- 特殊效果：增加NPC成长速度10%
- 说明：帮助对方修炼，建立深厚友谊

**特殊事件互动：**

**生日祝福**（特殊事件）
- 好感度：+20
- 消耗：200灵石
- 触发：NPC生日当天
- 最低等级：友好（好感41+）

**危机援助**（特殊事件）
- 好感度：+30
- 消耗：500灵石+5丹药
- 触发：NPC遇到危机
- 最低等级：友好（好感41+）

**成就祝贺**（特殊事件）
- 好感度：+10
- 消耗：无
- 触发：NPC突破境界或达成成就
- 最低等级：认识（好感21+）

**特殊功能：**
- **传授功法**：师尊专属，好感达到60/90时解锁不同功法
- **共同修炼**：师兄师姐专属，好感达到一定程度可一起修炼
- **指导修炼**：师弟师妹专属，帮助他们成长

**阵营互动影响：**
- 正派NPC：执行魔道任务会降低好感
- 魔道NPC：帮助正派会降低好感
- 中立NPC：不受阵营影响

### NPC成长

**NPC也会成长：**
- 有自己的修炼进度
- 可以突破境界
- 可以飞升成仙
- 成长会影响互动效果
